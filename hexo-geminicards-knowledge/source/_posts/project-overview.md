## 项目简介

GeminiCards 是一个基于 React + TypeScript 开发的智能闪卡应用，旨在帮助用户通过 AI 生成的闪卡进行高效学习。该应用利用通义千问 API 分析用户输入的话题或上传的文件，自动生成结构化的闪卡，包含问题、选项、答案和详细解析。

## 核心功能

1. **智能闪卡生成**：通过通义千问 API 分析用户输入的话题或上传的文件，自动生成结构化的闪卡
2. **多难度级别**：支持基础、进阶和专家三个难度级别的闪卡生成
3. **文件上传**：支持上传图像、PDF 和 Word 文档作为闪卡生成的数据源
4. **学习模式**：提供交互式学习模式，支持闪卡翻转、答案验证和学习进度追踪
5. **学习统计**：记录学习过程中的数据，生成详细的学习统计报告
6. **错题本**：自动收集用户标记为未掌握的闪卡，提供专项复习功能
7. **数据持久化**：使用 IndexedDB 进行本地数据存储，确保数据安全可靠
8. **响应式设计**：适配不同屏幕尺寸，提供良好的移动端体验

## 技术栈

- **前端框架**：React 19.2.3 + TypeScript 5.8.2
- **构建工具**：Vite 6.2.0
- **样式方案**：Tailwind CSS
- **状态管理**：React useState/useEffect 钩子
- **数据持久化**：IndexedDB
- **AI 服务**：通义千问 API（qwen-plus 模型）
- **图标库**：Lucide React

## 架构设计

### 组件架构

- **App.tsx**：应用的主组件，负责状态管理、路由控制和组件协调
- **StudyView.tsx**：学习模式的核心组件，管理学习会话的流程和统计
- **FlashcardComponent.tsx**：单个闪卡的展示组件，处理闪卡翻转和答案验证

### 服务架构

- **qwenService.ts**：与通义千问 API 交互，负责生成闪卡数据
- **memoryService.ts**：管理本地数据存储，使用 IndexedDB 实现数据持久化

### 数据流设计

1. **闪卡生成数据流**：用户输入 → qwenService 调用 API → 返回闪卡数据 → App 组件更新状态 → memoryService 保存数据
2. **学习数据流**：用户选择闪卡集 → StudyView 组件渲染 → 用户交互 → 更新学习统计 → App 组件更新全局统计 → memoryService 保存数据
3. **数据加载数据流**：应用初始化 → memoryService 加载数据 → App 组件设置初始状态

## 应用场景

- **学术研究**：上传论文或教材，生成核心知识点闪卡
- **考试备考**：针对特定考试内容，生成针对性的复习闪卡
- **语言学习**：生成词汇、语法等语言学习闪卡
- **职业技能**：针对专业技能点，生成系统性的学习闪卡
- **知识巩固**：将日常学习的内容转化为闪卡，加强记忆效果

## 未来发展
